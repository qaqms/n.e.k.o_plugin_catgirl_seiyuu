# 猫娘声优 · 使用指南

装好后怎么玩，四步：

## 0. 安装与启用

1. 插件中心导入 `.neko-plugin` 包；
2. **手动启用/启动一次插件进程**：本插件 fail-closed，不会自动启动；
   面板动作需要插件进程在跑才能执行；
3. 游戏建议保持**窗口化/无边框窗口**（v0.2 起大部分全屏窗体也能直接拍
   窗口本体；只有 DirectX 独占全屏两条通道都可能截到黑帧）。

## 1. 找到游戏窗口并框选对话框

1. 打开剧情游戏；
2. 进入本插件面板 →「刷新窗口」——列表是**全部候选窗口**（前台置顶带
   ★，最小化的带 [min]，每行附进程名），在过滤框里输入游戏名/进程名
   关键字即可缩小范围；选中游戏（或选「跟随前台」）→ 点「截取预览」；
3. 在预览画面上**拖拽框住游戏对话框**所在区域 → 点「保存区域」；
4. 可点「测试识别」确认能读到台词文字。

> 配音期间其它窗口盖在游戏上也不会干扰识别——拍的是游戏窗口本体，
> 不是它那块屏幕。若某游戏拍出来是黑屏，把设置里的「截屏方式」改成
> 「仅桌面截屏」并让游戏保持前台。

## 2. 开始配音

- 面板点「开始配音」，或对猫娘说 **"打开配音模式"**；
- 她会**逐字**朗读每一行新出现的台词：一句播完才播下一句，不接话、不解说；
- 打字机效果由"稳定窗口"消化（文本连续几帧不变才开口），间隔可在设置里调。
  默认开启的「句末标点优先」会堵死打字机增长中的半句：未说完的句子（句号
  前）不会开口，句读结尾的整句只等两帧完全一致就播；不满意可在配音规则里
  关掉该开关退回纯 N 帧窗口。

## 3. 停止 / 暂停

- 对猫娘说 **"结束配音"**，或面板点「停止配音」；
- 你在聊天里说话时配音会**自动暂停**让位于你；说完对她说 **「继续配音」**
  （或面板点「继续」）就接着上一句继续念，不用重新选窗口。

> 用语音「打开配音模式」时默认跟随前台窗口：若前台是 N.E.K.O 自己的窗口会
> 直接拒绝（防止她朗读了自己的聊天记录无限自激）；想精确指定游戏，请在面板
> 里选好目标窗口再点「开始配音」。

## 规则微调

- 主角第一人称台词配不配：`朗读主角台词` 开关 + 主角名列表；
- 内心独白（（）或「」包裹）配不配：`朗读内心独白` 开关；
- 系统按钮/菜单词：加进 `UI 屏蔽词`；
- 被跳过的行会出现在「跳过的行」列表，方便你发现误杀并补词。

## 安全说明

本插件**不注入、不读取游戏进程内存**，只让系统把窗口画面渲染出来再识别
文字（PrintWindow / 桌面截屏两条通道都是系统层只读能力），
对任何游戏（包括网游）零封号风险。截屏内容只在本地处理，不会上传。
