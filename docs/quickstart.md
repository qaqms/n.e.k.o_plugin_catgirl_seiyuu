# 猫娘声优 · 使用指南

装好后怎么玩，三步：

## 1. 找到游戏窗口并框选对话框

1. 打开剧情游戏（请保持**窗口化 / 无边框窗口**模式，独占全屏会截到黑屏）；
2. 进入本插件面板 →「目标窗口」选中游戏（或选"跟随前台"）→ 点「截取预览」；
3. 在预览画面上**拖拽框住游戏对话框**所在区域 → 点「保存区域」；
4. 可点「测试识别」确认能读到台词文字。

## 2. 开始配音

- 面板点「开始配音」，或对猫娘说 **"打开配音模式"**；
- 她会**逐字**朗读每一行新出现的台词：一句播完才播下一句，不接话、不解说；
- 打字机效果由"稳定窗口"消化（文本连续几帧不变才开口），间隔可在设置里调。

## 3. 停止 / 暂停

- 对猫娘说 **"结束配音"**，或面板点「停止配音」；
- 你在聊天里说话时配音会**自动暂停**让位于你，说完点「继续」即可。

> 用语音「打开配音模式」时默认跟随前台窗口：若前台是 N.E.K.O 自己的窗口会
> 直接拒绝（防止她朗读了自己的聊天记录无限自激）；想精确指定游戏，请在面板
> 里选好目标窗口再点「开始配音」。

## 规则微调

- 主角第一人称台词配不配：`朗读主角台词` 开关 + 主角名列表；
- 内心独白（（）或「」包裹）配不配：`朗读内心独白` 开关；
- 系统按钮/菜单词：加进 `UI 屏蔽词`；
- 被跳过的行会出现在「跳过的行」列表，方便你发现误杀并补词。

## 安全说明

本插件**不注入、不读取游戏进程内存**，只在桌面层截屏 + 识别文字，
对任何游戏（包括网游）零封号风险。截屏内容只在本地处理，不会上传。
